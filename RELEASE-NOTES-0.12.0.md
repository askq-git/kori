# Kori 0.12.0 - Windows beta

Kori 0.12 makes production-quality OBS camera movement faster to set up while
keeping detailed control available when it is needed.

## What's new

- Five Camera Styles: Natural Push, Slow Drama, Documentary Push, Punch In and
  Awkward Zoom.
- A cleaner settings window organised into Camera movement, Playback and Focus.
- A compact style summary with collapsible Fine-tune controls.
- Subtle, Cinematic and Strong motion blur during camera movement.
- Safe reset controls for one target or all saved Kori settings.
- Hotkeys that persist across OBS restarts and Kori upgrades.
- A guided installer and uninstaller that display versions, planned file
  changes and verification results.

## Requirements

- Windows 10 or Windows 11
- OBS Studio 31.1 or newer
- Standard OBS scenes

## Upgrade

Close OBS, extract the ZIP and run `Install Kori.cmd`. Installing over an older
Kori version preserves OBS scenes, hotkeys and saved Kori settings.

Kori remains beta software. Please report problems through GitHub Issues or at
kori.dev@askq.co.nz.
