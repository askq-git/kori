# Contributing to Kori

Kori is not currently accepting unsolicited code contributions or pull
requests.

You are welcome to:

- report a bug;
- suggest a feature or workflow improvement; or
- fork the project under the terms of its licence.

If you would like to work directly with ASKQ on Kori, email
**kori.dev@askq.co.nz** before preparing any code.

Keeping official development coordinated through ASKQ gives the project a
clear product direction and keeps future licensing and commercial options
manageable.
