# Kori Support

Kori is an early beta. Clear reports help make it safer and easier to use.

## Before opening an issue

1. Confirm you are using 64-bit OBS Studio 31.1 or newer.
2. Confirm Kori appears in **Tools > Kori Settings**.
3. Reproduce the problem with the latest Kori release.
4. In OBS, open **Help > Log Files > View Current Log**.
5. Collect the lines containing `[Kori]`.

## Where to ask

- Use the bug report form for repeatable faults, crashes or unexpected
  behaviour.
- Use the feature request form for workflow and effect ideas.
- Email **kori.dev@askq.co.nz** if you cannot use GitHub.
- Do not publish security-sensitive details. Follow [SECURITY.md](SECURITY.md).

Please include the Kori version, OBS version, Windows version, source type,
whether Studio Mode was active, reproduction steps and relevant Kori log lines.

Camera-driver, capture-device and video-format errors that do not contain a
`[Kori]` log entry are usually outside the plugin and should be tested in OBS
with Kori temporarily disabled.
