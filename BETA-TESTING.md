# Help test Kori

Thanks for trying the Kori Windows beta.

Kori adds smooth camera-style zooms to normal OBS scenes. This beta is intended
for real production testing before a wider release.

## Before you begin

- Use Windows 10 or 11.
- Use 64-bit OBS Studio 31.1 or newer.
- Save or back up your OBS scene collection before testing any new plugin.
- Kori currently supports the standard OBS canvas.

## Install

1. Download the Windows ZIP from the Kori release.
2. Extract the ZIP.
3. Close OBS.
4. Run **Install Kori.cmd**.
5. Open OBS and choose **Tools > Kori Settings**.

The installer is not yet signed, so Windows may show an unrecognized-app
warning.

## What we would like you to try

- Zoom towards a face or object.
- Return smoothly to the starting view.
- Try different zoom speeds and motion styles.
- Save different settings for two cameras.
- Zoom an entire scene containing overlays or logos.
- Trigger a zoom automatically when a scene becomes live.
- Use Kori during a normal recording or production rehearsal.

## Send feedback

Please tell us:

- what you were trying to create;
- what felt easy or confusing;
- whether anything moved unexpectedly;
- your OBS and Windows versions; and
- the relevant `[Kori]` lines from the OBS log if something failed.

Use a GitHub issue or email **kori.dev@askq.co.nz**.

Do not include passwords, stream keys or other private information in logs or
screenshots.

## Remove Kori

Close OBS, then run **Uninstall Kori.cmd** from the extracted package.
