# Kori 0.10.0

The first Kori Windows beta.

## Highlights

- Smooth zoom and return for an individual source or the entire scene.
- Clickable and draggable focus-point picker.
- Saved settings for different sources and scenes.
- Manual hotkeys or automatic activation when a scene becomes live.
- Start delay, hold, automatic return and multiple motion styles.
- Windows installer and uninstaller.

## Compatibility

- Windows 10 or 11, 64-bit
- OBS Studio 31.1 or newer
- Standard OBS canvas
